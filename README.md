# Agency Website

A modern and responsive Agency Website built using HTML, CSS, JavaScript, and Bootstrap.  
This project showcases a professional business landing page with smooth UI design, responsive layouts, and interactive sections.

## 🚀 Live Demo
https://sarveshbait.github.io/Agency-Website/

---

## 📌 Features

- Fully Responsive Design
- Modern UI/UX Layout
- Bootstrap Components
- Smooth Navigation
- Services Section
- About Section
- Contact Section
- Interactive Animations
- Mobile Friendly Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## 💻 Installation & Usage

1. Clone the repository

```bash
git clone https://github.com/SarveshBait/Agency-Website.git
```

2. Open the project folder

```bash
cd Agency-Website
```

3. Run the project

Open `index.html` in your browser.
